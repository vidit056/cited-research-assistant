1. Executive Summary

The Cited Research Assistant is an agentic Retrieval-Augmented Generation (RAG) system engineered to transform complex natural-language research questions into verifiable, cited Markdown reports.

Unlike general-purpose chatbots that produce ungrounded generations without citations, this system makes the entire research process transparent, inspectable, and verifiable. It decomposes queries, gathers live web evidence via Tavily, chunks and indexes content with Google Vertex AI embeddings, synthesizes cited text, and runs an adversarial verification pass to locate exact character spans in raw source text while surfacing cross-source contradictions.

2. Architecture & Data Flow

1. Plan Node

Decomposes 1 broad research query into 3–5 targeted sub-questions using gemini-3.7-flash.

2. Retrieve & RAG

Queries Tavily, extracts clean text via trafilatura, chunks text, and indexes in local Chroma DB with text-embedding-004.

3. Synthesize

Generates structured Markdown report with inline [n] bracket citations grounded strictly on retrieved excerpts.

4. Verify & Conflicts

Verifies quotes using rapidfuzz fuzzy span matching, flags unverified claims, and detects contradictions.
